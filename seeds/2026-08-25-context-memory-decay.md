# Recall and use of context facts may decay with token distance\n\n- **Origin:** Pierre, 2026-08-25.\n- **Intervention:** Place one fixture-grounded fact at preregistered token distances earlier in an otherwise inert rendered context, then ask the agent to complete a later task that requires recalling and using that fact. Hold model, harness, task, fact wording, tool schemas, decoding, and oracle fixed.\n- **Prediction:** Correct recall and artifact use may remain stable at short distances and decline as the fact moves farther back in the context window. The curve may be flat or non-monotonic, so actual provider token distance must be measured rather than inferred from message count.\n- **Boundary:** The effect may depend on fact salience, competing information, summarization, retrieval tools, and whether the task merely repeats the fact or must apply it. This does not establish a general context-window limit or transfer across models or harnesses.\n- **Possible experiment:** Register a context-distance dose-response task with a deterministic artifact oracle that requires applying the fact, not quoting it. Use a small low-to-high distance grid, fresh episodes at every dose, and neutral filler that contains neither competing instructions nor answer cues. Add salience and retrieval as separately powered follow-up axes.\n
