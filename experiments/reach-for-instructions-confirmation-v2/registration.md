# Reach-for-instructions held-out confirmation registration v2

V1 began eight episodes but was stopped before completion when its retained
artifacts exposed two grounded forms absent from the oracle preflight: an
approved removal expressed as not executed, and a parenthetical owner role.
The V1 report preserves that invalid measurement evidence. V2 is a fresh,
result-informed oracle-calibration rerun. It changes no delivery condition,
task facts, user request, context dose, model, reasoning setting, harness,
tools, skill description, procedure, decoding, sample size, or outcome process
requirements.

## Fixed plan

- **Experimental unit:** one fresh agent episode in a new private filesystem.
- **Task and conditions:** the held-out Cedar Loop access-transition fixture and
  opaque `G01`/`G02` delivery policies from V1. G01 receives the full procedure
  in system context; G02 loads the identical procedure through the same fixed
  skill tool. The natural request names no tool, skill, path, source file, or
  oracle phrase.
- **Only V2 change:** the preflight now accepts the two observed grounded
  forms. It still rejects an unsupported account. The same condition-blind
  semantic rule is used in both conditions.
- **Context and sample:** 0, 900, and 3,600 inert filler lines; 12 fresh
  episodes per delivery-by-dose cell, 72 total. The fresh paired-block schedule
  uses seed `20260827`. There is no early stop or post-result replacement.
- **Runtime:** the same pinned Qwen3.6-27B Q4, reasoning disabled, temperature
  0.1, 1,200 output tokens, current Assist Deep Agents tool loop, recursion
  limit 20, private virtual filesystem, default filesystem/TODO/task tools, and
  one fixed `load_skill` tool. No caller tools or subagents are present.
- **Resource boundary:** execute at most 24 admitted terminal episodes per
  invocation, then take a 15-minute GPU break before resuming the same sealed
  schedule. This is an operational fairness boundary, not a result-dependent
  stop rule; no analysis occurs until the full 72-episode schedule completes.
- **Primary outcome and missingness:** exactly one grounded JSON handoff,
  immutable sources, inventory, and all source reads before writing. Every
  admitted terminal outcome remains with its reason code. A shared-resource
  denial retries the same scheduled episode before advance.
- **Analysis:** report complete-pass counts by delivery and dose, the aggregate
  contrast over 36 fresh episodes per arm, token counts, and skill-load timing.
  It may establish only a held-out-task delivery result on this pinned model and
  harness, never a context threshold or Assist product action.
