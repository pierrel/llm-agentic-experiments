# Reach-for-instructions development v4 report

All 18 sealed episodes were admitted and completed. The deterministic primary
oracle recorded 18 artifact failures, nine for each opaque delivery condition
at every context dose. This does not support a guidance-delivery conclusion:
inspection of the retained raw traces showed that 16 episodes wrote a grounded
JSON handoff with natural alternate field names, while two wrote no JSON file.

The common alternate forms were `verified_amount_cents` for the requested
verified amount and `remaining_uncertainty` for uncertainty. Payment status
used direct normalized forms including `not_paid` and `no_payment_issued`.
V5 is separately sealed to calibrate only those oracle aliases. V4 remains the
evidence that an overconstrained structured oracle can erase a behavior signal.
