# Context-length development v3 design review

V2 revealed that a single exact phrase could reject a handoff that stated the
same required fact in an equally direct form. V3 changes only that oracle
surface, before seeing any V3 model output.

- Scientific integrity: the acceptable forms are declared before the run and
  correspond to the same retained-image fact, not condition-specific answers.
- Statistical rigor: the result remains a three-episode development screen;
  V3 cannot estimate a rate or establish a threshold.
- Agentic fit: current Deep Agents, the clean Assist source, model, reasoning
  setting, and loop remain unchanged.
- Minimum adequate setup: no semantic judge is introduced. The oracle stays
  deterministic while recognizing the three natural phrasings observed or
  conventionally direct for this fact.

V3 closes the planned development series. Any product or confirmation decision
must rely on the archived results and a separately sealed held-out design.
