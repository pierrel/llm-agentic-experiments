# Documentation map

## Start here

Read this map, then [Design 0001](0001-agentic-guidance-experiments.md) for the
first experiments, the [registration template](0002-study-registration-template.md)
before any model run, and the [results template](0003-results-report-template.md)
when interpreting a cohort. The [plain-English walkthrough](example-study-walkthrough.md)
uses invented data to make the loop concrete; the [glossary](glossary.md)
translates recurring technical terms.

| Document | Role |
| --- | --- |
| [0000 Initial repository report](0000-initial-documentation-report.md) | What this setup contains and what remains deliberately unbuilt. |
| [0001 Agentic guidance experiments](0001-agentic-guidance-experiments.md) | Program design and the first two studies. |
| [0002 Study registration template](0002-study-registration-template.md) | Immutable per-study plan before model results. |
| [0003 Results report template](0003-results-report-template.md) | Required evidence and interpretation after a cohort. |
| [Example study walkthrough](example-study-walkthrough.md) | Invented end-to-end example, not evidence. |
| [Glossary](glossary.md) | Short plain-language definitions. |
| [Study registry](study-registry.md) | Index of study versions and their status. |
| [0004 Initial design review](0004-initial-design-review.md) | Findings and resolutions from the first review panel. |
| [0005 Current Assist baseline](0005-current-assist-baseline.md) | Historical current-Assist baseline profile and result capsule. |
| [Result capsules](../results/README.md) | Committed run history, evidence, learnings, and product/blog handoffs. |
| [Hypothesis seeds](../seeds/README.md) | Product claims captured as testable research leads. |

`AGENTS.md` is the operating contract for scientific integrity, review, and GPU
coordination. This directory records designs and reports; the MVP's executable
condition and scripted-provider manifests now live under `experiments/mvp-scripted/`.
