## Review decisions and stop boundary

The design reviewers' concrete findings were resolved as follows:

- The existing four tag-bound keys remain canonical: `scientific-validity`,
  `statistical-validity`, `harness-integrity`, and
  `minimum-adequate-setup`. They are the repository's scientific-integrity,
  statistical-rigor, agentic-harness-fit, and minimum-setup lenses.
- Exact final review artifacts live in the local coordination review record
  before tagging. The eventual annotated tag must embed those same four Terra
  results and the dependent Sol signoff; the runner verifies their full text,
  hashes, candidate commit/tree, coordinator, model, disposition, and
  dependency digest.
- Authorization and server restoration remain workspace-orchestrator effects,
  not experimental inputs. The accepted candidate is explicitly
  `tag-pending`; neither a tag, runtime preparation, server change, model
  admission, merge, nor result exists without a later explicit authorization.
- Same-UID identity spoofing is outside the documented cooperative protocol's
  security boundary. The bounded shared event slice is retained because it
  fail-closes on ambiguous gate evidence without changing a treatment.

The separate process retrospective requested for this recovery is operational,
not scientific. It is recorded and verified through the meta-repository's
coordination state and final report after completion. Conversation records and
coordination implementation changes remain outside this registration, manifest,
capsule, analysis, and research results.
