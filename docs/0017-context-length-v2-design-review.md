# Context-length development v2 design review

V1 was flat at three realized prompt sizes. V2 tests the seed's predicted
boundary condition, task complexity, while preserving the context intervention.

- Scientific integrity: filler remains inert and before the unchanged procedure;
  model, runtime, schedule form, and deterministic trace oracle remain fixed.
- Statistical rigor: three fresh episodes are only a development screen; no
  threshold or general effect is claimed from it.
- Agentic fit: the same current Deep Agents filesystem/TODO/task profile and
  clean Assist source worktree are used.
- Minimum adequate setup: nine source inputs create factual reconciliation,
  cancellation-versus-payment, and uncertainty work without adding skills,
  external data, or a qualitative judge.

If V2 remains flat, one final sealed development variant must be attempted
where feasible before any confirmation decision.
