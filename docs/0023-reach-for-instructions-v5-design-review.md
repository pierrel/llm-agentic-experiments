# Reach-for-instructions v5 design re-review

V4's complete, sealed cohort found no primary passes because its oracle fixed
two JSON field names that the model naturally paraphrased. V5 introduces the
predeclared alias pairs documented in its new fixture and registration.

- **Scientific integrity:** V4 remains archived unchanged. V5 names the exact
  observed alias forms before any V5 request and does not add condition-specific
  answers or alter the user request.
- **Statistical rigor:** the same 18 fresh episodes and interleaved schedule are
  retained. V5 is a development variant, not a replacement analysis of V4.
- **Agentic harness fit:** aliases apply to the JSON artifact only; inventory,
  source reads, write ordering, immutable sources, tool set, and skill-loading
  process outcome are unchanged.
- **Minimum adequate setup:** accepting two direct field-name variants is the
  smallest correction that tests the stated behavior rather than a naming
  convention. No semantic judge, extra task, or new factor is added.
