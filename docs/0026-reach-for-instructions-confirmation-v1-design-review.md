# Reach-for-instructions held-out confirmation v1 design review

This review occurs before model admission. It follows the valid V7 development
screen without reusing its reimbursement task, facts, or output domain.

## Scientific integrity

The held-out Cedar Loop access-transition fixture is new. `G01` and `G02`
differ only in when the identical procedure becomes model context; both retain
the same catalog, tool, files, decoding, and inert context dose. The natural
request does not mention a skill, tool, source path, output path, or oracle.
The request is captured at the model boundary and compared with its sealed
post-middleware render before scoring. The source fixture, condition map,
preflight, schedule, implementation, settings, and result chain are sealed
before a model request. No completed V7 value changes this task or oracle.

## Statistical rigor

The unit is one fresh isolated episode. Twelve episodes per delivery-by-dose
cell yield 36 per delivery arm and 72 total, a fixed aggregate confirmation
screen that is materially larger than V7's 9 per arm. The seed `20260826`
deterministically interleaves condition pairs across doses. Admission denial is
administrative missingness and retries the same trial; every admitted terminal
episode remains. The aggregate delivery contrast is primary; dose cells and
skill-load timing are prespecified diagnostics. The study neither claims power
for a precise dose interaction nor stops early after a favorable result.

## Agentic harness fit

The study retains the current Deep Agents loop, fresh private virtual
filesystem, and a single fixed skill-loading tool. Those are the minimum
current-Assist mechanisms needed to compare host-delivered and agent-retrieved
guidance. The condition-blind oracle checks final facts, source immutability,
inventory, and reads-before-write. The preflight proves it accepts two grounded
forms, including aliases for account and uncertainty, and rejects a fact absent
from the fixture. It guards against the exact-phrase failures that invalidated
earlier development results.

## Minimum adequate setup

The separate access-transition task is necessary to test transfer beyond the
reimbursement fixture. Three context doses retain the response-surface question
without adding task, skill-count, model, reasoning, or architecture axes. Twelve
episodes per cell are necessary to enlarge the aggregate confirmation arm while
keeping a bounded, single-model cohort. There is no network, real user data,
production filesystem, qualitative judge, caller tool, or subagent because none
is required for the causal contrast. The retained request capture, preflight,
and process-group timeout containment are measurement requirements, not added
experimental features.

## Decision

Proceed only after the no-model preflight and integrity tests pass, the bundle
is tagged, and the pinned Assist source revision is clean. Interpret a result
only as a held-out task replication within the pinned model and Deep Agents
harness; do not change Assist guidance from this cohort alone.
