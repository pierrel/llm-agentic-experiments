# Access-transition oracle calibration gate

V1 and V2 both stopped because their deterministic handoff oracle rejected
grounded language variants. This gate is a prerequisite to a new Qwen3.8
confirmation. It is not a model experiment and makes no treatment comparison.

## Scientific integrity

The corpus is condition-blind and uses no model output beyond the V2 failure
families that motivated it. Each accepted status family states the same fixture
fact: removal was approved and remains unexecuted or unrevoked. Each rejected
family changes that fact, an account identifier, the owner role, the required
action, or the uncertainty. The gate must pass before a fresh cohort begins;
no V1 or V2 episode is rescored or pooled.

## Statistical rigor

This is an exhaustive unit-level validity gate, not an estimate: every corpus
case must receive its declared label. It does not consume model samples or
create an early stopping rule. A later confirmation retains its separately
registered 72 fresh episodes, randomization, reason-coded outcomes, and
delivery-by-context analysis.

## Agentic harness fit and minimum setup

The gate imports no model, agent, filesystem backend, prompt, tool, or skill.
It evaluates only the final structured handoff semantics that the runtime
oracle will call. It keeps a deterministic grammar rather than adding a judge,
network dependency, or an open-ended semantic model. Its fixture is the same
Cedar Loop factual source used by the invalid runs.

## Decision rule

The gate passes only when every accepted and rejected corpus record matches its
declared label. A passing gate authorizes a new model-specific registration,
not a modification to V2. A gate failure stops the program for another design
review; it never broadens the runtime checker after a cohort begins.

## Local review record

The local review found and corrected false-pass paths for a completed or
contradictorily revoked removal, a negated approval, wrong or negated actions,
asserted asset certainty, and non-string account aliases. The final corpus and
focused regressions cover those paths. The review sandbox could not create
temporary directories, while the repository evaluation environment ran the
complete suite successfully.
