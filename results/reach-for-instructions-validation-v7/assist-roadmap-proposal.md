# Proposed Assist roadmap item

## Proposed outcome

No Assist behavior change yet. Add a laboratory roadmap item for a held-out
confirmation of progressive versus always-present procedural guidance before
changing where Assist places a procedure.

## Evidence and limits

This is supported by the valid but exploratory V7 capsule. Retrieved guidance
passed 5/9 complete artifact checks versus 2/9 for always-present guidance, but
there are only three episodes per context cell and no established context-length
interaction. The confirmation must use a new natural task and independent
fixture, retain the matched procedure, catalog, tools, model, reasoning setting,
and Deep Agents harness, and preregister a larger per-cell sample. Before model
admission, its condition-blind artifact oracle must accept a small set of known
valid alternatives and reject a known unsupported fact.

Current Assist guidance, its skill-loading contract, and adjacent task behavior
must remain unchanged while the confirmation runs.

## Product action

**Roadmap item:** confirm the guidance-delivery response surface on one
held-out procedural task, including the 0/900/3,600-line context doses, then
decide whether a product experiment is warranted. Report all terminal outcomes,
skill-load timing, captured provider requests, and per-cell counts. Do not
implement or merge an Assist change from this result without Pierre's explicit
decision.
